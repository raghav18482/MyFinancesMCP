Connect MyFinanceMCP to Your AI Assistant

Connect this MCP server to Claude Desktop, Cursor, or any MCP client that can send an HTTP header. Your assistant can then read your Angel One portfolio and market data and help you analyse it. It is read-only: it cannot place, modify or cancel orders, and any trade idea it gives you is hypothetical.

Don't want to set up MCP? The web dashboard has the same read-only assistant built in. No MCP configuration needed.
1

Create a personal access token

The MCP server identifies you by a personal access token that you create here and paste into your client. This is a simple bearer token — not OAuth: there is no sign-in pop-up, and you never type Angel One credentials into an AI chat.

  • Shown once. We store only a hash of it.
  • Expires after 30 days by default (up to 90), and you can revoke it here at any time.
  • Grants portfolio:read only. Anyone holding it can read your portfolio, so treat it like a password.

Claude Desktop

Find your config file

macOS
~/Library/Application Support/Claude/claude_desktop_config.json
Windows
%APPDATA%\Claude\claude_desktop_config.json

Add the MCP server

Claude Desktop reaches remote servers through mcp-remote (installed automatically by npx; needs Node.js). The token goes in an environment variable, not in the command line:

claude_desktop_config.json
{
  "mcpServers": {
    "angelone-portfolio": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote", "{{ server_url }}/mcp/mcp",
        "--header", "Authorization:${AUTH_HEADER}"
      ],
      "env": { "AUTH_HEADER": "Bearer mfm_your_token_here" }
    }
  }
}

Restart Claude Desktop, then ask things like "Show my portfolio summary" or "How concentrated are my holdings?"

3

Cursor IDE

Create or edit .cursor/mcp.json:

.cursor/mcp.json
{
  "mcpServers": {
    "angelone-portfolio": {
      "url": "{{ server_url }}/mcp/mcp",
      "headers": { "Authorization": "Bearer mfm_your_token_here" }
    }
  }
}
Keep this file out of git — it contains your token.
4

Other MCP Clients

Any client that speaks the Streamable HTTP transport and can send a custom header works:

URL:    {{ server_url }}/mcp/mcp
Header: Authorization: Bearer mfm_your_token_here
Clients that only support OAuth sign-in (for example ChatGPT connectors) cannot use these tokens. The old /mcp/sse endpoint has been removed.

Run Locally (Self-Hosted)

Terminal
git clone https://github.com/raghav18482/MyFinancesMCP.git
cd MyFinancesMCP
pip install -r requirements.txt
python main.py

Open http://localhost:8000, enroll, create a token on this page, and point your client at http://localhost:8000/mcp/mcp with the same header.

Available Tools (all read-only)

ToolDescription
portfolio_summaryOverall portfolio: invested, current value, P&L
get_holdings / get_all_holdingsStock holdings with P&L per stock, and totals
get_positionsOpen intraday / delivery positions
get_fundsAvailable cash, margin, and net value
get_order_book / get_trade_bookToday's orders and executed trades (history only)
get_profileAccount profile
search_scrip / get_ltp / get_market_depthFind instruments, last price, order-book depth
get_candle_data / get_stock_historyHistorical OHLC data
calculate_pnlP&L for one symbol
predict_price_directionTechnical-signal outlook (not advice)

There are no order, login or account-changing tools.

Security

  • Your Angel One credentials are encrypted at rest on the server and are never sent to, or typed into, the AI model
  • The MCP server is read-only: no tool can place, modify or cancel an order
  • Each token sees only its owner's data; revoking it takes effect on the next request
  • All traffic goes over HTTPS when deployed
